# WorkBuddy 自动化提示词（可直接粘贴）

请创建一个自动化任务，名称：`法院送达短信日汇总`，每天 **18:00** 执行：

使用「法院送达短信日汇总」Skill 与 QQ 邮箱连接器，完成以下工作：

1. 读取近 24 小时主题含 `[法院送达]` 或正文含 `NEED_DOWNLOAD=` 的邮件。
2. 按 Skill 规则解析：案号、事由、链接、期限。
3. 生成今日清单：哪个案子、什么事、要不要动、截止时间。
4. 凡有下载链接或 `NEED_DOWNLOAD=yes` 的条目，单独列出「待下载」并提醒我尽快打开链接保存 PDF/文书。
5. 凡有开庭/期限或 `NEED_CALENDAR=yes` 的条目，给出日历事件草案（标题、时间、提前提醒），并提醒我写入系统日历或滴答清单。
6. 把 `汇总.md` 与原文摘录保存到文件夹：`~/法院送达/{{今天日期}}/`。
7. 执行结束后用一句话摘要推送到我的手机：今日 N 条，待下载 X，待建日程 Y。

首次请先手动跑通一次再启用定时。
